Web Server & LAN Access

How to access this web application from your mobile phone or other computers.

To access this invitation web suite from your smartphone, tablet, or another computer on the same Wi-Fi network:

  1. Run the app on your host machine: python app.py
  2. Find your computer's local IP address (e.g., 192.168.1.15)
  3. Open your mobile browser and navigate to: http://192.168.1.15:5000/
  4. You can now upload contacts, design the position, generate PDFs, and dispatch directly on mobile WhatsApp!

Cloud Deployment

Deploy to cloud services (Render, Railway, Heroku, VPS).

This web app is 100% cloud-ready. It uses standard Flask and PyMuPDF:

  • Port configuration: Reads $PORT environment variable automatically.
  • Render / Railway: Set Start Command: python app.py or waitress-serve --port=$PORT app:app
  • Zero Tkinter constraint: The visual canvas position editor runs completely in the browser!
